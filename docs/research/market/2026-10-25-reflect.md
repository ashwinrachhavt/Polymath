# Market research: Reflect

**Date:** 2026-10-25 · **Analyst:** overnight build session · **Status:** current as of July 2026 sources
**Category:** AI-native networked notes, daily-notes-first.

## What it is

A fast, minimalist networked-notes app that rebuilt itself in July 2026 as
**Reflect Open**: local-first, open-source, plain-Markdown-file storage, with
the original hosted app ("Reflect Classic") still maintained. The rebuild is a
direct response to the AI era: Markdown is "the common language for both
people and AI," so the notes folder itself became the product. [S1][S2]

## Current feature set (verified 2026-10-25)

- **Local Markdown graph**: `daily/`, `notes/`, `assets/` folders; the index
  is rebuildable from the files; open in any editor, script against it. [S1]
- **Daily notes, backlinks, wiki-links, tags, templates** in a live-preview
  Markdown editor. [S1]
- **AI chat with citations over your notes** - answers link back to source
  notes - plus inline rewrite/summarize/translate and saved prompts. **BYOK**:
  your own OpenAI/Anthropic/Google/OpenRouter key, requests go directly to the
  provider, no Reflect account involved. [S1][S2]
- **Privacy scoping**: notes marked private are never sent to AI or any
  content-reading service. [S1]
- **Tasks**: Markdown checkboxes collect into a searchable task view with
  scheduling, completion, archiving. [S1]
- **Audio memos** transcribed into the daily note via your chosen provider. [S1]
- **Browser capture extension**: links, selections, screenshots, page text. [S1]
- **Apple Calendar + Contacts integration**: events beside the daily note,
  meeting notes, people notes linked to contacts. [S1]
- **Sync via iCloud Drive or Git** (GitHub remote you own); keys in the OS
  keychain. [S1]
- **CLI**: `reflect today`, `reflect search`, `reflect show` - scripts and
  agents read notes without scraping the app. [S1]
- Optional **local semantic search** on-device. [S1]

## Business model

Mac app free and open source; iPhone/iPad via paid subscription (existing
Classic subscribers got a free year). AI cost is the user's own provider bill.
Classic hosted plans historically ~$10/mo. [S1][S2][S3]

## Strengths

- The **data-model answer**: no proprietary database, no lock-in, notes as
  files agents and scripts can read natively. A CLI as a first-class surface.
- BYOK aligns cost with use and removes the privacy middleman.
- Speed and keyboard-first capture discipline.

## Weaknesses

- **Apple-only** (Mac/iOS); no web or Windows/Android story.
- Markdown checkboxes are not tasks with states, owners, or outbox-processed
  side effects; the task view is a projection, not a system.
- Single-player; no workspace, tenancy, or review flows.
- The graph is links between pages - there is no claim-level structure
  (zettels, evidence, verification).

## What Axiom can assimilate

1. **The agent-accessible data posture.** Reflect's bet - the data layer
   should be natively readable by agents - is Axiom's bet too, taken further:
   Axiom exposes typed domains and proposals instead of files. Their CLI is
   the idea in miniature; Axiom's Eve tool surface is the grown-up version.
2. **BYOK as a supported route.** The provider registry already models
   workspace-owned keys; Reflect validates that users accept provider-direct
   billing for AI features. Axiom's free-first registry + BYOK is a clean
   cost story. (Registry: `src/integrations/providers/registry.ts`.)
3. **Privacy scoping at the note level.** A `private` marker that hard-excludes
   content from every model route would fit the capture/artifact schema and
   the sensitiveDataAllowed flag the registry already carries per provider.
4. **Audio memo -> daily note** via the capture pipeline (audio capture kind +
   extraction/transcription stage).
5. **Calendar beside the daily note** - the daybook + calendar domains
   already have the data; the layout idea is the takeaway.

## Where Axiom can differentiate

1. **Proposals with verification, not just chat with citations.** Reflect
   answers questions; Axiom's zettel pipeline *verifies quotes against source
   text* before saving a claim (#293). Citation links vs. verified claims.
2. **Real task system.** Tasks with states, snoozes, links to captures and
   projects, and an outbox - not checkbox projections.
3. **Multi-surface capture with a classification ladder** (Tier 0-3:
   normalize, structure heuristics, LLM enrichment, type classifier) vs. a
   browser extension that saves page text.
4. **Cross-platform** (web app, any device) vs. Apple-only.
