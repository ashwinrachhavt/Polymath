# Market research series

Overnight competitive research for Axiom / the personal-OS space. Each entry
is one dated document per product, verified against live sources on its date,
ending with what Axiom can **assimilate** (adopt, mapped to real seams) and
where it can **differentiate** (win, mapped to real strengths).

## Method

- Primary sources first (official blogs, pricing pages, docs); secondary
  reviews only for sentiment, and labeled as such.
- Every capability claim carries its source; pricing claims are dated.
- Takeaways name the Axiom seam they map to (or explicitly say "no seam yet").
- These documents are deliverables: they live outside the build path and add
  no dependencies.
