# Market research: Notion

**Date:** 2026-10-25 · **Analyst:** overnight build session · **Status:** current as of 2026-10-25 sources
**Category:** team workspace / docs + databases; the "one tool to run your company."

## What it is

The workspace incumbent: blocks, pages, databases, wikis, projects, and now a
full agent layer. Notion's 2025-2026 trajectory is decisive for the whole
category: it stopped being a docs tool with AI features and became **an agent
platform with a docs tool attached**. [S1]

## Current feature set (verified 2026-10-25, notion.com/pricing)

- **Blocks/pages/databases** with subtasks, dependencies, custom properties;
  forms, sites, charts, dashboards; Notion Calendar included. [S1]
- **Notion Agent** (Business tier): chat, generate, autofill, translate over
  workspace content; **Research mode** in beta. [S1]
- **AI Meeting Notes** (Business tier). [S1]
- **Enterprise Search** (beta, Business tier): search across connected tools. [S1]
- **Custom Agents**: user-built agents that "handle repetitive tasks
  autonomously," metered separately - $10 per 1,000 monthly credits after a
  free trial. [S1]
- **Workers** (beta): custom code extending Notion - build agent tools, sync
  external data, trigger Notion workflows from outside. [S1]
- Enterprise: zero data retention with LLM providers, SCIM, audit log, DLP/SIEM. [S1]

## Business model

Per-member SaaS: Free / Plus $10 / Business $20 / Enterprise custom. The AI
capabilities gate on Business; agent *usage* is metered again on top via
Notion credits. AI is the upsell engine, and autonomous agents are a separate
consumption line. [S1]

## Strengths

- **The database block model**: structured data and prose in one surface is
  still the most flexible general-purpose model in the category.
- Distribution and habit: "put it in Notion" is the default for teams.
- Agent monetization clarity: credits make agent cost an explicit meter.

## Weaknesses

- **Personal knowledge is a side effect**: the data model serves team
  coordination; a personal second brain inherits workspace ceremony
  (teamspaces, permissions, guests) for nothing.
- **Agents act on the workspace, not for the person**: Custom Agents automate
  team chores; they do not triage your life, and every 1,000 credits costs
  $10 - autonomous help is a metered luxury.
- No capture-classification pipeline, no claim verification, no local or
  offline story of consequence.

## What Axiom can assimilate

1. **Agent metering as a visible, honest line item.** Notion credits make
   agent spend legible to the buyer. Axiom's quota ledger already enforces
   caps; surfacing usage the same way (per route, per period) is cheap and
   builds the same trust. (`src/integrations/providers/quota.ts`.)
2. **Workers-style extension points.** A documented way to add custom tools
   to the agent without forking: Axiom's Skills system and Eve tool registry
   are the seeds; Notion validates the demand.
3. **Research mode** - a bounded, multi-step "go find out" agent run with a
   cited report at the end maps to Axiom's agent engine + Studio report
   generation. The reading summarizer (#293) already produces the
   claims+questions half.
4. **AI Meeting Notes** maps to the transcript capture + extraction + zettel
   pipeline; the differentiator below applies.

## Where Axiom can differentiate

1. **Personal by construction**: one workspace per life, capture-to-action
   loops (inbox triage, proposals, tasks, daybook) that Notion's team-shaped
   model does not have and cannot add without betraying its buyer.
2. **Verification before storage**: zettels verify quotes against source
   text; Notion's agent output is trusted on fluency. For a *personal* system
   of record, provable beats plausible.
3. **Free-first cost posture**: Axiom's registry refuses silent paid fallback
   and runs baseline intelligence on verified free tiers. Notion's agent
   usage bills by the thousand credits. For individuals, predictable-free
   beats metered-maybe.
4. **Offline/dev honesty**: local Postgres + dev stack vs. a cloud-only
   workspace whose free tier degrades for 2+ members.
