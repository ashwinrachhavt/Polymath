### Safety migration blockers/cautions

1. **Unlisted model rates do not fail closed.** UI says missing rates block affected call, but backend `model_rate` invents $0.50/M input and $1.50/M output for any unlisted model; tool rates do fail closed. Do not claim verified budget ceiling for arbitrary custom model IDs. `/workspace/donors/command-center/apps/api/src/command_center/db/spending.py:164-181`; `/workspace/donors/command-center/apps/api/tests/test_spending.py:384-410`; UI `/workspace/donors/command-center/apps/web/src/components/workspace/spending.tsx:124-130`.
2. **Disabled paid calls can be reactivated.** Ordinary `prepare_run_spending` and connected-call paths preserve disabled policy, but helper `ensure_default_spending_policy` only returns existing policy if active; otherwise creates/reconfigures active $100/$10 defaults. Legacy/standalone POST `agent-runs` calls helper unconditionally. This is a path-specific bypass of the Paid calls paused expectation, not a claim all sends reactivate it. `/workspace/donors/command-center/apps/api/src/command_center/db/spending.py:1213-1254`; `/workspace/donors/command-center/apps/api/src/command_center/api/agents.py:217-225`.
3. **Approved attachment membership/name may drift.** Worker joins only nonarchived artifacts, builds surviving list without asserting equality to approved attachment set and names files from mutable artifact title. Archive can omit attachment; rename can alter filename. Fail closed or pin membership/name. `/workspace/donors/command-center/apps/api/src/command_center/actions/worker.py:101-122`; `/workspace/donors/command-center/apps/api/src/command_center/db/reviewed_actions.py:1044-1059`.
4. **Preflight is not atomic remote CAS.** Local account/expiry checked at claim, then provider identity/source/upload work; no final local recheck just before write. Queued-only revoke cannot recall in-flight effect. Remote revision comparison doesn't close edit race without conditional provider write. `/workspace/donors/command-center/apps/api/src/command_center/actions/worker.py:76-83,233-295`; `/workspace/donors/command-center/apps/api/src/command_center/db/reviewed_actions.py:748-752`; README `:116`.
5. **Malformed post-dispatch response may become definitive failed.** Adapter settles cost then raises ProviderFailure on malformed/error response; worker maps to failed, which permits new revision. Ambiguous response after dispatch should stay UNKNOWN unless nonexecution proved. `/workspace/donors/command-center/apps/api/src/command_center/integrations/composio_actions.py:1080-1089`; `/workspace/donors/command-center/apps/api/src/command_center/actions/worker.py:321-323`; `db/reviewed_actions.py:656-657`.
6. **Successful reconciliation replay checks state too early.** Route requires unknown/partial before replay lookup; after success changes to succeeded, same key can fail state validation rather than replay saved result. `/workspace/donors/command-center/apps/api/src/command_center/api/reviewed_actions.py:1356-1384,1438-1440`.
7. **Budget is local accounting, not invoice/immediate kill switch.** Existing period/work/run snapshots persist limits; settled cost can exceed reserved bound after charge; apply-defaults can reactivate without caller expected version. Axiom must define hard policy fences across running work. Rate-card no-edit API/hash convention is not equivalent to DB-enforced immutable review history: no rate-card UPDATE/DELETE reject trigger found. `/workspace/donors/command-center/apps/api/src/command_center/db/spending.py:108-162,240-245,497-560,798-825,992-1027,1213-1237`; `api/spending.py:437-455`; `/workspace/donors/command-center/apps/api/migrations/versions/0014_spending_controls.py:21-43,277-285`.
8. **Automation false-submit/unknown requeue/receipt deficiencies** from §10 are excluded from the generally sound reviewed-action contracts. Never assume all donor mutations or “automation” inherit the safer action state machine.
